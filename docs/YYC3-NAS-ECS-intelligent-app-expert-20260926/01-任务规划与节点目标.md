# 📋 YYC³ NAS-ECS 优化任务规划与节点目标

> **执行有规划，规划有节点，节点有目标，目标可评估**

## 一、总体目标

基于《00-项目现状审核报告》的发现，通过 **4 个阶段** 的整改，将项目从当前 **C+ 级 (65.05分)** 提升至 **A 级 (≥85分)**，实现：

- ✅ 生产构建可通过（当前阻断）
- ✅ TypeScript 类型检查零错误（当前 1276）
- ✅ 安全配置达到生产标准（当前弱默认密钥 + CORS 通配）
- ✅ 测试通过率 100%（当前 99.9%）
- ✅ ESLint 零警告（当前 81 warnings）

## 三、详细任务分解

### Phase 1: P0 阻断修复

#### Task 1.1: 修复生产构建断链导入

**目标**: `vite build --mode production` 成功退出
**验收标准**:
- [ ] `src/App.tsx` 中 `./app/lib/ai-integration` 导入路径修正
- [ ] `IntelligentAIWidgetWrapper` 组件创建或替换
- [ ] `LogViewer` 组件实现或路由移除
- [ ] `npx vite build --mode production` 退出码 0
**依赖关系**: 无
**风险点**: `IntelligentAIWidgetWrapper` 可能需要参考 `IntelligentAIWidget` 的 API 设计包装层
**完成标记**: ⬜ 未开始

#### Task 1.2: 隔离 services/ai 类型检查

**目标**: 根 `tsc --noEmit` 仅检查 src/，services/ai 独立检查
**验收标准**:
- [ ] 根 `tsconfig.json` 移除 `services` 或添加 `exclude`
- [ ] `.github/workflows/ci-cd.yml` 为 services/ai 添加独立 type-check 步骤
- [ ] 根 `tsc --noEmit` 错误数降至 ≤ 53（仅 src/）
**依赖关系**: 无
**风险点**: 需确认 services/ai 不被 src/ 直接引用
**完成标记**: ⬜ 未开始

#### Task 1.3: 修复 src/ 中 53 个 TypeScript 错误

**目标**: `tsc --noEmit` 在 src/ 范围内零错误
**验收标准**:
- [ ] 修复路径别名解析错误（DocQualityDashboard 等）
- [ ] 修复 API 响应类型与实际结构对齐（APIModule, api-v2）
- [ ] 修复 env.ts 中 boolean/string 比较
- [ ] 修复 EmailApp.tsx ModuleTheme 导出
- [ ] `tsc --noEmit` 退出码 0
**依赖关系**: Task 1.2
**风险点**: API 类型漂移可能需要同时调整 mock 数据
**完成标记**: ⬜ 未开始

#### Task 1.4: 添加强制 JWT 密钥校验

**目标**: 生产环境弱密钥无法启动
**验收标准**:
- [ ] `create_app()` 中生产环境校验 `JWT_SECRET_KEY` 存在且 ≥32 字符
- [ ] `SECRET_KEY` 同样校验
- [ ] 单元测试覆盖校验逻辑
**依赖关系**: 无
**风险点**: 需确保测试环境使用 TestingConfig（已禁用）
**完成标记**: ⬜ 未开始

### Phase 2: P1 安全加固

#### Task 2.1: 收紧 CORS 策略

**目标**: 生产环境 CORS 不允许通配符
**验收标准**:
- [ ] `CORS_ORIGINS` 生产默认值改为空，启动时校验非 `*`
- [ ] docker-compose.yml 中 `CORS_ORIGINS` 移除默认 `*`
- [ ] 文档更新 CORS 配置说明
**完成标记**: ⬜ 未开始

#### Task 2.2: 清理前端敏感环境变量

**目标**: `VITE_` 前缀无真实密钥
**验收标准**:
- [ ] 审计所有 `VITE_` 变量，确认无 JWT/密码/API Key
- [ ] `VITE_AUTH_JWT_SECRET` 重命名为非敏感用途或移除
- [ ] 后端密钥仅通过非 `VITE_` 变量配置
**完成标记**: ⬜ 未开始

#### Task 2.3: 移除硬编码基础设施信息

**目标**: 源码无硬编码 IP/域名
**验收标准**:
- [ ] `NAS_SERVER_IP` 默认值移除，强制环境变量
- [ ] 检查其他硬编码 IP/域名
**完成标记**: ⬜ 未开始

#### Task 2.4: 修复失败测试

**目标**: `vitest run` 100% 通过
**验收标准**:
- [ ] `EnvironmentSwitcher.test.tsx` 断言更新为 `bg-blue-primary`
- [ ] 全部 1016 测试通过（0 failed）
**完成标记**: ⬜ 未开始

#### Task 2.5: 集成 env_validator 到启动流程

**目标**: 生产环境配置不合规则拒绝启动
**验收标准**:
- [ ] `create_app()` 调用 `env_validator.validate()`
- [ ] 校验失败抛出明确错误
**完成标记**: ⬜ 未开始
