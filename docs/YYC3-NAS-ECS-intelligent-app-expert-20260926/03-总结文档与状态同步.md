## 遇到的问题与解决方案

| 问题 | 解决方案 | 经验教训 |
| ---- | -------- | -------- |
| `.env.example` 跨两行的真实 JWT 密钥 | 占位符替换 + CHANGELOG 轮换警示 | 泄漏检测要看换行续行，不止单行匹配 |
| tar 部署包内嵌套 `.env.production` | tar tzf 检查内容后出库 | 二进制产物入库前必须检查包内容 |
| `bunx audit` / 直接 CodeQL analyze 等 CI 无效写法 | 重写为 `bun pm audit` / init→autobuild→analyze | workflow 需按当前 Action 主版本逐一核对 |
| secrets 在 step 级 if 中判断不可靠 | 移除 if，用 continue-on-error 吞掉无 token 失败 | secrets 上下文渲染时机与直觉不符 |
| **本地构建绿、远程构建红**（Pages 断链） | 根因：裸 `logs/`、`lib/` gitignore 规则致 4 个源文件从未入库；追加豁免规则补齐后 Pages 连续 success | "本地绿 ≠ 远程绿"必须以 push 后流水线为准；模板化 gitignore 需审计裸规则 |
| black 升 24.3.0 后立即暴露 <26.3.1 high 告警 | 同步升级 26.3.1，open alerts 归零 | 依赖修复要看最新 advisory，不只看 first_patched |
| IDE import-organizer / AI 自动修复竞态 | 编辑间隙自动重排 import 致 SearchReplace 锚点失配；误改 `maxMetrics`→`maxEntries` 致测试失败 | 编辑前重新 Read 取最新内容；自动修复产物需逐一复核，不能盲信 |
| TS 对象字面量类型宽化连锁错误 | `priority: 'normal'` 推断为 string 而非字面量类型，23 处测试断言连锁失败 | 对象赋值加显式类型注解（`const x: T = {...}`），错误会在源头而非下游消解 |
| frps.toml 新 token 不能写回 git 跟踪文件 | 直接写入会造成新泄漏 | Go template 环境变量注入 + gitignored secrets 文件分离 |
