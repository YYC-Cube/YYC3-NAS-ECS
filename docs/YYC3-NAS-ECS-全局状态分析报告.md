## 🏗️ 1. 项目结构与组织

项目采用清晰的模块化架构，符合企业级标准：

```
YYC3-NAS-ECS/
├── api/                    # Python Flask后端API
├── services/               # 独立微服务（AI、DDNS、FRP、Redis等）
```
