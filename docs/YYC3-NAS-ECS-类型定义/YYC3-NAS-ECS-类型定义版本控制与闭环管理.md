## 📦 版本控制机制

### 版本号规范

#### 语义化版本 (Semantic Versioning)

**格式**：MAJOR.MINOR.PATCH

```
MAJOR.MINOR.PATCH
  |      |      |
  |      |      +--- 修订版本号：向下兼容的问题修复
  |      +---------- 次版本号：向下兼容的功能新增
  +---------------- 主版本号：不兼容的API变更
```

#### 版本号示例

```
1.0.0 → 1.0.1  (修复bug，向下兼容)
1.0.1 → 1.1.0  (新增功能，向下兼容)
1.1.0 → 2.0.0  (重大变更，不向下兼容)
2.0.0 → 2.0.1  (修复bug，向下兼容)
2.0.1 → 2.1.0  (新增功能，向下兼容)
2.1.0 → 3.0.0  (重大变更，不向下兼容)
```

### 版本标记

#### JSDoc 版本标记

```typescript
/**
 * @version 1.0.0
 * @created 2026-01-25
 * @updated 2026-02-03
 * @deprecated 2.0.0
 * @replacement NewInterfaceName
 * @since 1.0.0
 */
export interface OldInterface {
  // ...
}

/**
 * @version 2.0.0
 * @created 2026-02-03
 * @since 2.0.0
 */
export interface NewInterface {
  // ...
}
```

#### 版本标记说明

| 标记 | 说明 | 使用场景 |
|------|------|---------|
| `@version` | 版本号 | 所有类型定义 |
| `@created` | 创建日期 | 所有类型定义 |
| `@updated` | 更新日期 | 所有类型定义 |
| `@deprecated` | 废弃标记 | 即将废弃的类型 |
| `@replacement` | 替代类型 | 废弃类型的替代方案 |
| `@since` | 起始版本 | 新增的类型 |

### 变更记录

#### @changelog 标记

```typescript
/**
 * @version 1.0.0
 * @changelog
 * - 初始版本
 * - 定义核心类型接口
 * - 实现基础功能
 */
export interface ChatMessage {
  id: string;
  role: 'user' | 'assistant' | 'system';
  content: string;
  timestamp: number;
}

/**
 * @version 1.1.0
 * @changelog
 * - 新增 metadata 属性
 * - 新增 status 属性
 * - 新增 reactions 属性
 * - 优化 timestamp 类型为 number
 */
export interface ChatMessage {
  id: string;
  role: 'user' | 'assistant' | 'system';
  content: string;
  timestamp: number;
  metadata?: Record<string, any>;
  status?: 'sending' | 'sent' | 'delivered' | 'read' | 'error';
  reactions?: MessageReaction[];
}

/**
 * @version 2.0.0
 * @changelog
 * - 修改 role 类型为枚举 MessageRole
 * - 新增 attachments 属性
 * - 修改 timestamp 类型为 Date
 * - 移除 metadata 属性（使用独立的 metadata 接口）
 */
export interface ChatMessage {
  id: string;
  role: MessageRole;
  content: string;
  timestamp: Date;
  attachments?: Attachment[];
  status?: MessageStatus;
  reactions?: MessageReaction[];
}
```

### 兼容性管理

#### 向后兼容策略

```typescript
/**
 * @version 2.0.0
 * @deprecated 3.0.0
 * @replacement NewInterface
 * @description 旧版本接口，保持向后兼容
 */
export interface OldInterface {
  oldProperty: string;
  newProperty?: string;  // 可选，保持兼容
}

/**
 * @version 3.0.0
 * @since 3.0.0
 * @description 新版本接口
 */
export interface NewInterface {
  newProperty: string;
  additionalProperty: string;
}
```

#### 迁移指南

```typescript
/**
 * 类型迁移指南
 *
 * @description 从 OldInterface 迁移到 NewInterface 的步骤
 *
 * @steps
 * 1. 更新所有 OldInterface 引用为 NewInterface
 * 2. 将 oldProperty 替换为 newProperty
 * 3. 添加 additionalProperty 的值
 * 4. 运行类型检查确保无错误
 * 5. 运行测试确保功能正常
 * 6. 更新相关文档
 *
 * @example
 * ```typescript
 * // 旧代码
 * const old: OldInterface = { oldProperty: 'value' };
 *
 * // 新代码
 * const new: NewInterface = {
 *   newProperty: 'value',
 *   additionalProperty: 'additional'
 * };
 * ```
 */
```
