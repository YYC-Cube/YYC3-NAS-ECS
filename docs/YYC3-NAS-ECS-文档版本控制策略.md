## 🎯 版本控制原则

### 1. 语义化版本控制（Semantic Versioning）

#### 版本号格式

```
主版本号.次版本号.修订号 (MAJOR.MINOR.PATCH)
```

#### 版本号规则

- **主版本号（MAJOR）**: 不兼容的 API 修改
- **次版本号（MINOR）**: 向下兼容的功能性新增
- **修订号（PATCH）**: 向下兼容的问题修正

#### 示例

```
1.0.0 → 1.1.0  (次版本号：新增功能)
1.1.0 → 1.1.1  (修订号：修复问题)
1.1.1 → 2.0.0  (主版本号：不兼容的变更)
```

---

### 2. 版本号使用场景

#### 2.1 文档版本

**适用范围**: 所有 Markdown 文档

**版本号位置**: 文档头部

```markdown
# 文档标题

> **文档编号**: YYC3-NAS-ECS-DOC-001
> **创建日期**: 2026-01-31
> **版本**: 1.0.0
> **作者**: YYC³ Team
> **更新日期**: 2026-01-31
```

#### 2.2 代码版本

**适用范围**: TypeScript/JavaScript 文件

**版本号位置**: 文件头部注释

```typescript
/**
 * @file 文件描述
 * @description 详细描述
 * @module 模块名
 * @author YYC³
 * @version 1.0.0
 * @created 2026-01-31
 * @updated 2026-01-31
 */
```

## 📊 版本控制策略

### 1. 版本递增规则

#### 1.1 自动递增

**触发条件**:
- 文档内容修改
- 代码功能新增
- Bug 修复

**递增规则**:
- 修复问题: PATCH +1
- 新增功能: MINOR +1, PATCH = 0
- 不兼容变更: MAJOR +1, MINOR = 0, PATCH = 0

#### 1.2 手动递增

**触发条件**:
- 重大重构
- 架构变更
- 版本里程碑

**递增规则**:
- 根据变更类型手动指定版本号

---

### 2. 版本号同步策略

#### 2.1 相关文档同步

**规则**: 相关文档应保持版本号一致

**示例**:
```
TypeScript问题解决最终报告.md: 2.0.0
TypeScript问题解决与文档同步计划.md: 2.0.0
TypeScript错误解决报告.md: 2.0.0
```

#### 2.2 文档与代码同步

**规则**: 文档版本应反映代码版本

**示例**:
```
package.json: 1.0.0
README.md: 1.0.0
API文档.md: 1.0.0
```

---

### 3. 版本回滚策略

#### 3.1 回滚触发条件

- 严重错误
- 不兼容问题
- 用户反馈问题

#### 3.2 回滚流程

```
1. 评估回滚必要性
   ↓
2. 选择回滚目标版本
   ↓
3. 创建回滚分支
   ↓
4. 执行回滚操作
   ↓
5. 验证回滚结果
   ↓
6. 记录回滚日志
   ↓
7. 通知相关人员
```

#### 3.3 回滚记录

```json
{
  "rollbackId": "ROLLBACK-20260131-001",
  "rollbackTime": "2026-01-31T10:00:00Z",
  "fromVersion": "2.0.0",
  "toVersion": "1.1.0",
  "reason": "严重错误导致功能不可用",
  "rolledBackBy": "maintainer@example.com",
  "status": "completed"
}
```

---

### 2. 备份保留策略

#### 2.1 保留期限

- 近期版本（30天）: 完整保留
- 中期版本（90天）: 压缩保留
- 长期版本（1年）: 归档保留

#### 2.2 保留数量

- 主版本: 无限制
- 次版本: 保留最近 10 个
- 修订版本: 保留最近 20 个

---

## 🚀 版本控制工具

### 1. Git 版本控制

#### 1.1 版本标签

```bash
# 创建版本标签
git tag -a v1.0.0 -m "版本 1.0.0"

# 推送标签
git push origin v1.0.0

# 列出标签
git tag -l

# 删除标签
git tag -d v1.0.0
```

#### 1.2 版本分支

```bash
# 创建版本分支
git checkout -b release/v1.0.0

# 合并版本分支
git merge release/v1.0.0

# 删除版本分支
git branch -d release/v1.0.0
```

---

### 2. 自动化工具

#### 2.1 版本号自动递增

```bash
# 递增修订号
npm version patch

# 递增次版本号
npm version minor

# 递增主版本号
npm version major
```

#### 2.2 变更日志自动生成

```bash
# 生成变更日志
npm run docs:changelog

# 生成指定版本的变更日志
npm run docs:changelog -- --from=v1.0.0 --to=v2.0.0
```
