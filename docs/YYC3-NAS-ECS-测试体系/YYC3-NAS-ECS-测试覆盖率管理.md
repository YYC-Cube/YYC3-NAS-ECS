## 🎯 覆盖率标准

### 覆盖率类型

#### 1. 语句覆盖率（Statement Coverage）

**定义**：被执行的语句占总语句的百分比。

**计算公式**：

```
语句覆盖率 = (被执行的语句数 / 总语句数) × 100%
```

**目标值**：≥90%

**示例**：

```typescript
function add(a: number, b: number): number {
  const result = a + b;  // 语句1
  return result;          // 语句2
}

// 如果执行 add(1, 2)，语句覆盖率为 100%
// 如果不执行该函数，语句覆盖率为 0%
```

#### 2. 分支覆盖率（Branch Coverage）

**定义**：被执行的分支占总分支的百分比。

**计算公式**：

```
分支覆盖率 = (被执行的分支数 / 总分支数) × 100%
```

**目标值**：≥85%

**示例**：

```typescript
function isPositive(num: number): boolean {
  if (num > 0) {  // 分支1
    return true;    // 分支1-true
  } else {          // 分支1-false
    return false;
  }
}

// 如果执行 isPositive(1)，分支覆盖率为 50%（只覆盖了true分支）
// 如果执行 isPositive(1) 和 isPositive(-1)，分支覆盖率为 100%
```

#### 3. 函数覆盖率（Function Coverage）

**定义**：被执行的函数占总函数的百分比。

**计算公式**：

```
函数覆盖率 = (被执行的函数数 / 总函数数) × 100%
```

**目标值**：≥95%

**示例**：

```typescript
function add(a: number, b: number): number {
  return a + b;
}

function subtract(a: number, b: number): number {
  return a - b;
}

function multiply(a: number, b: number): number {
  return a * b;
}

// 如果只执行 add()，函数覆盖率为 33.33%
// 如果执行 add() 和 subtract()，函数覆盖率为 66.67%
// 如果执行所有函数，函数覆盖率为 100%
```

#### 4. 行覆盖率（Line Coverage）

**定义**：被执行的代码行占总代码行的百分比。

**计算公式**：

```
行覆盖率 = (被执行的代码行数 / 总代码行数) × 100%
```

**目标值**：≥90%

**示例**：

```typescript
function add(a: number, b: number): number {
  const result = a + b;  // 第1行
  return result;          // 第2行
}

// 如果执行 add(1, 2)，行覆盖率为 100%
// 如果不执行该函数，行覆盖率为 0%
```

#### Vitest覆盖率工具

**工具**：@vitest/coverage-v8

**配置**：

```typescript
import { defineConfig } from 'vitest/config';

export default defineConfig({
  test: {
    coverage: {
      provider: 'v8',
      reporter: ['text', 'json', 'html'],
      exclude: [
        'node_modules/',
        'src/test/',
        '**/*.d.ts',
        '**/*.config.*',
        '**/mockData',
        'dist/',
      ],
      include: ['src/**/*.{ts,tsx}'],
      lines: 90,
      functions: 95,
      branches: 85,
      statements: 90,
      perFile: false,
      all: true,
    },
  },
});
```


## 📈 覆盖率提升

### 提升策略

#### 1. 增加测试用例

**策略**：通过增加测试用例来提高覆盖率

**方法**：

- 分析未覆盖的代码
- 设计测试用例覆盖未覆盖的代码
- 执行测试用例并验证覆盖率

**示例**：

```typescript
// 原始代码
function add(a: number, b: number): number {
  if (a > 0 && b > 0) {
    return a + b;
  } else {
    return 0;
  }
}

// 原始测试用例
it('应该返回两个正数的和', () => {
  expect(add(1, 2)).toBe(3);
});

// 增加测试用例
it('应该返回0当a或b为负数', () => {
  expect(add(-1, 2)).toBe(0);
  expect(add(1, -2)).toBe(0);
  expect(add(-1, -2)).toBe(0);
});
```

#### 2. 优化测试用例

**策略**：通过优化测试用例来提高覆盖率

**方法**：

- 分析测试用例的覆盖范围
- 优化测试用例的测试数据
- 增加测试用例的测试场景

**示例**：

```typescript
// 原始测试用例
it('应该添加日志', () => {
  const log = { level: 'info', message: 'Test', source: 'test', category: 'general' };
  logService.addLog(log);
  expect(logService.queryLogs()).toHaveLength(1);
});

// 优化测试用例
it('应该添加日志', () => {
  const logs = [
    { level: 'info', message: 'Test 1', source: 'test', category: 'general' },
    { level: 'warn', message: 'Test 2', source: 'test', category: 'monitoring' },
    { level: 'error', message: 'Test 3', source: 'test', category: 'error' }
  ];
  
  logs.forEach(log => logService.addLog(log));
  
  const queriedLogs = logService.queryLogs();
  expect(queriedLogs).toHaveLength(3);
  expect(queriedLogs[0].level).toBe('info');
  expect(queriedLogs[1].level).toBe('warn');
  expect(queriedLogs[2].level).toBe('error');
});
```

#### 3. 增加边界测试

**策略**：通过增加边界测试来提高覆盖率

**方法**：

- 分析代码的边界条件
- 设计边界测试用例
- 执行边界测试用例并验证覆盖率

**示例**：

```typescript
// 原始代码
function calculateAge(birthYear: number): number {
  const currentYear = new Date().getFullYear();
  return currentYear - birthYear;
}

// 原始测试用例
it('应该计算年龄', () => {
  expect(calculateAge(2000)).toBeGreaterThan(0);
});

// 增加边界测试用例
it('应该计算年龄', () => {
  expect(calculateAge(2000)).toBeGreaterThan(0);
});

it('应该处理边界情况', () => {
  const currentYear = new Date().getFullYear();
  expect(calculateAge(currentYear)).toBe(0);
  expect(calculateAge(currentYear - 1)).toBe(1);
  expect(calculateAge(currentYear - 100)).toBe(100);
});
```

#### 4. 增加异常测试

**策略**：通过增加异常测试来提高覆盖率

**方法**：

- 分析代码的异常处理
- 设计异常测试用例
- 执行异常测试用例并验证覆盖率

**示例**：

```typescript
// 原始代码
function divide(a: number, b: number): number {
  if (b === 0) {
    throw new Error('Division by zero');
  }
  return a / b;
}

// 原始测试用例
it('应该返回商', () => {
  expect(divide(10, 2)).toBe(5);
});

// 增加异常测试用例
it('应该返回商', () => {
  expect(divide(10, 2)).toBe(5);
```

### 监控工具

#### 1. Vitest覆盖率监控

**工具**：@vitest/coverage-v8

**配置**：

```typescript
import { defineConfig } from 'vitest/config';

export default defineConfig({
  test: {
    coverage: {
      provider: 'v8',
      reporter: ['text', 'json', 'html'],
      thresholds: {
        lines: 90,
        functions: 95,
        branches: 85,
        statements: 90
      }
    },
  },
});
```

**使用**：

```bash
# 运行测试并检查覆盖率阈值
npm run test:coverage

# 如果覆盖率低于阈值，测试将失败
```

#### 2. Codecov覆盖率监控

**工具**：Codecov

**配置**：

```yaml
# codecov.yml
coverage:
  status:
    project:
      default:
        target: auto
        threshold: 1%
        informational: true
        base: auto
    patch:
      default:
        target: auto
        threshold: 1%
        informational: true
        base: auto
```

**使用**：

```bash
# 上传覆盖率报告到Codecov
npm run test:coverage && codecov
```

#### 3. Coveralls覆盖率监控

**工具**：Coveralls

**配置**：

```json
{
  "scripts": {
    "test:coverage": "vitest run --coverage",
    "coveralls": "cat coverage/lcov.info | coveralls"
  }
}
```

**使用**：

```bash
# 上传覆盖率报告到Coveralls
npm run test:coverage && npm run coveralls
```
