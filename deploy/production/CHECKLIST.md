## 🚀 部署步骤详解

### 步骤 1: 执行本地测试

```bash
# 在本地运行完整测试
cd deploy/local-test
./run-local-staging.sh --full

# 确保所有测试通过
```

### 步骤 2: 执行 Staging 测试

```bash
# 在 Staging 服务器执行
cd /opt/yyc3-nas-ecs/deploy/staging
./verify-staging.sh --full

# 查看测试报告
```

### 步骤 3: 执行生产部署

```bash
# SSH 登录到生产服务器
ssh user@production-server

# 导航到部署目录
cd /opt/yyc3-nas-ecs/deploy/production

# 执行部署（约 5-10 分钟）
./deploy-production.sh

# 监控日志输出
tail -f /opt/yyc3-nas-ecs/logs/production-deploy-*.log
```

### 步骤 4: 验证生产部署

部署完成后，验证以下内容：

```bash
# 1. 健康检查
curl https://api.yyc3.com/api/v2/health

# 2. 检查容器状态
docker-compose ps

# 3. 检查日志（前 50 行）
docker-compose logs --tail=50 api

# 4. 检查错误日志
docker-compose logs api | grep -i error | tail -20

# 5. 检查资源使用
docker stats
```

## 🔄 回滚预案

### 回滚触发条件

满足以下任一条件时立即回滚：

1. **严重功能故障**
   - 核心服务不可用（API 健康检查失败）
   - 用户无法登录/访问
   - 数据丢失风险

2. **性能严重下降**
   - API P95 响应时间 > 2 秒
   - 错误率 > 5%
   - 系统崩溃

3. **安全问题**
   - 发现安全漏洞
   - 数据泄露风险
   - 未授权访问

### 回滚步骤

```bash
# 快速回滚（约 3-5 分钟）
cd /opt/yyc3-nas-ecs/deploy/production
./rollback-production.sh

# 完整回滚（代码 + 数据库）
./rollback-production.sh --database

# 恢复特定备份
./rollback-production.sh --backup-name production-backup-20260204-120000
```

### 回滚后验证

- [ ] 服务恢复正常
- [ ] 健康检查通过

- [ ] 无严重错误日志
